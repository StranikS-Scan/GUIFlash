##### World of Tanks - Mods

## .. GUIFlash ..

## English
Allows you to dynamically create components for displaying text and graphic information in the Flash interface of the game World of Tanks. Components are created and managed using Python scripts (client modifications).

Learn more @ [**Wiki**](https://github.com/GambitER/GUIFlash/wiki).

## Russian
Позволяет динамически создавать компоненты для отображения текстовой и графической информации в Flash интерфейсе игры World of Tanks. Создание и управление компонентами производится через Python скрипты (модификации клиента).

Подробнее в [**Wiki**](https://github.com/GambitER/GUIFlash/wiki).
